# ⚽ Dashboard Brasileirão 2025 🏆

Olá. Sejam bem-vindos ao Dashboard Brasileirão 2025, um projeto experimental que realizei para um trabalho da faculdade, da matéria Interface e Usabilidade.

Aqui podemos encontrar as mais padrões tecnologias do desenvolvimento web, como:

- HTML
- -CSS
- JavaScript
- Chart.js

Criei esse meu primeiro dashboard, usando alguns gráficos que analisam média de gols, aproveitamento, partidas disputadas, histórico de pontuações, etc...

Queria agradecer aos meus companheiros de grupo, que puderam me ajudar a desenvolver parte do projeto.

(Digo já que o site foi totalmente desenvolvido para dark-mode, então usá-lo no light-mode poderá ter alguns erros.
